# GOOD RUSSIA HELP

Telegram-бот для приёма заявок в команду проекта.

## Возможности
- Заявки на администратора, хелпера и медиа-партнёра через пошаговые анкеты.
- Уведомление владельца Telegram ID `520362766` о каждой новой заявке.
- Кнопки одобрения и отклонения прямо под заявкой.
- Личное уведомление заявителя о решении.
- Админ-панель доступна только владельцу.
- SQLite хранит заявки и статусы.

## Запуск
1. Создайте бота через `@BotFather` и получите токен.
2. На Render создайте Background Worker из этого репозитория (или используйте `render.yaml`).
3. Добавьте переменную окружения `BOT_TOKEN` со своим токеном. `ADMIN_ID` уже задан как `520362766`.
4. Запустите сервис командой `python main.py`.
5. Откройте бота в Telegram и нажмите `/start`.

## Важно
- Токен не добавляйте в GitHub — только в Environment Variables на Render.
- На бесплатном Render локальная SQLite-база может сбрасываться при пересоздании/перезапуске инстанса. Для постоянного хранения подключите внешнюю БД или persistent disk на поддерживаемом тарифе.
- Картинка из ТЗ предназначена для аватара бота: установите её в `@BotFather` через `/setuserpic`.
